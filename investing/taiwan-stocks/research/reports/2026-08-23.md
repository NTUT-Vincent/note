## 2. 今天最重要的 3–5 個市場觀念

1. **漲價要先拆「需求定價權」與「成本轉嫁」。** 售價上升若只是記憶體或其他 BOM 成本被轉嫁，毛利率未必同步改善。
2. **產業 proxy 不等於公司財報。** Nvidia 財報可以驗證 AI infrastructure demand，但不能直接證明台積電、鴻海、緯創各自的 EPS／FCF 已改善。
3. **同一條 AI demand signal 不能重複計分。** Nvidia、TSMC、ODM／EMS 之間高度相關，應建立供應鏈依賴關係，避免把同一需求來源當成三份獨立證據。
4. **政策預算是 candidate-pool 證據，不是 individual-stock thesis。** 國防總預算提高只是第一層；下一層必須看到公司合約、交付、margin 與現金流。
5. **休市日最適合做 evidence hierarchy。** 沒有公司級新資料時，No change 是有效研究結果，不需要為了每日產出硬新增股票。

## 3. 今日教學主題

### L044｜Cost Pass-through vs Pricing Power：漲價不一定代表毛利率變好

**是什麼**：企業售價上升可能來自兩種不同經濟原因。第一是產品稀缺、品牌、技術或供需失衡帶來的 pricing power；第二只是上游成本上升後的 pass-through。

**為什麼重要**：兩者都會讓營收增加，但對毛利率與 ROIC 的含義完全不同。真正的 pricing power 通常可讓單位經濟改善；單純成本轉嫁可能只讓營收與成本同時上升。

**怎麼看**：
- ASP / 售價變化；
- BOM 與記憶體、晶片、電力、物流等成本；
- gross margin dollars 與 gross margin %；
- 營業利益率；
- working capital、OCF、FCF；
- 客戶是否接受價格，以及是否導致需求延後。

**常見誤區**：看到售價 +15%，就直接把獲利或 EPS 上調 15%。

**今日案例**：Nvidia AI server 價格上調逾 15% 的報導，主要理由包含記憶體成本急升。對鴻海、緯創來說，這不是 ODM／EMS margin 改善的直接證據；反而要追蹤材料成本、議價條款、客戶轉嫁能力、gross margin、AR／inventory 與 FCF。

### L045｜Supply-chain Evidence Graph：如何避免把同一需求重複計分

**是什麼**：把產業鏈證據畫成依賴關係，而不是把每一家公司的好消息當成彼此獨立。

簡化結構：

`Hyperscaler capex → Nvidia GPU / AI systems → TSMC wafer & advanced packaging → Foxconn / Wistron server assembly → company-specific margin / cash conversion`

**為什麼重要**：如果 Nvidia demand、TSMC capacity、鴻海 AI server 成長與緯創 AI server 成長都來自同一批 hyperscaler capex，不能把它們當成四個完全獨立的 bull evidence。

**怎麼看**：
- 先找 demand source；
- 再找每一層的瓶頸與 value capture；
- 最後檢查每家公司真正留住多少 gross profit、operating profit 與 FCF。

**常見誤區**：看到供應鏈每一家公司都報成長，就認為風險已被多重獨立證據分散。

**今日案例**：8/26 Nvidia 財報可驗證 AI 需求；若 data-center demand 強，台積電、鴻海、緯創的產業背景都會得到支持，但每家公司仍需要自己的 wafer mix、server mix、margin、working capital 與 FCF 證據。

## 4. 產業與資金輪動

今日台股休市，沒有新的 sector flow。最近有效台股結構仍是 8/21 breadth 擴散，而不是只有單一 AI 主線。

AI 供應鏈本週的研究主軸從「需求是否存在」進一步轉向「誰真正抓到 value」。Nvidia server 售價上升一方面可能反映供應緊張與需求韌性，另一方面也顯示 memory / BOM inflation。對台積電，核心是先進製程與 CoWoS 是否維持高 utilization、pricing 與高增量 ROIC；對鴻海與緯創，核心則是 server revenue mix 能否穿透至 gross margin、OCF/FCF，而不只推高營收與營運資金占用。

## 10. 今天可以學到什麼

今天最重要的是把「營收／售價成長」拆成經濟來源。價格上升可能是需求強、供給緊，也可能只是成本上升後被轉嫁；只有進一步看 gross margin、operating margin、OCF / FCF 與 ROIC，才能判斷公司是否真正創造更多價值。

第二個重點是避免 supply-chain double counting。Nvidia 需求強、TSMC 產能緊、鴻海與緯創 server 成長很可能是同一個 hyperscaler capex cycle 的不同節點。真正分散研究風險的方法，不是把同一需求鏈的公司全部當成獨立證據，而是看每一層的 value capture 與 cash conversion。
